# 🤝 Contributing to ThreadHopper

Thanks for showing interest in contributing to **ThreadHopper**!  
We’re building this for creators who value efficiency and creativity — your input matters 💡

---

## 🧰 Local Setup

1. **Fork** the repo
2. **Clone** your fork
   ```bash
   git clone https://github.com/rishaan007/thread-hopper-js.git
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Run the dev server**
   ```bash
   npm run dev
   ```

---

## 💡 How to Contribute

### 🪶 Report Bugs
If you find an issue, open a [GitHub Issue](https://github.com/rishaan007/thread-hopper-js/issues/new) with:
- Steps to reproduce  
- Expected vs actual behavior  
- Screenshots (if applicable)

### ⚙️ Suggest Features
Have an idea? Submit it via **Discussions → Ideas** or open an issue tagged with `feature`.

### 🧑‍💻 Code Contributions
1. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make changes and commit:
   ```bash
   git commit -m "Add feature: your feature name"
   ```
3. Push and open a Pull Request.

---

## 🧾 Code Style Guidelines

- Follow **ESLint + Prettier** rules.
- Use **TypeScript** for all new components.
- Keep components modular and accessible (ARIA-friendly).
- Use **Shadcn/UI** for consistent UI design.
