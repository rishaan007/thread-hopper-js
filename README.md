# 🧵 ThreadHopper

> AI-powered content repurposing tool — turn long-form content (blogs, newsletters, scripts) into platform-specific social media posts with one click.

---

## 🚀 Overview

**ThreadHopper** is an AI-powered web app that helps creators, marketers, and teams **repurpose content efficiently** and stay consistent across platforms.  
From a single input, it can generate:
- 🐦 Twitter/X threads  
- 💼 LinkedIn posts  
- 👾 Reddit discussions  
- ❄️ Instagram captions 

---

## 🧠 Tech Stack

- ⚡ **Vite + React + TypeScript**
- 🎨 **Shadcn/UI + Tailwind CSS**
- ☁️ **Supabase (Auth & Database)**
- 🤖 **AI Content Generation (OpenAI API)**

---

## 🛠️ Installation & Setup

Clone the repo:
```bash
git clone https://github.com/rishaan007/thread-hopper-js.git
cd thread-hopper-js
```

Install dependencies:
```bash
npm install
```

Set up environment variables in a `.env` file:
```bash
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key
VITE_OPENAI_API_KEY=your_openai_key
```
fork the file and check .env file for keys.

Run locally:
```bash
npm run dev
```
